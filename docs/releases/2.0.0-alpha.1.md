# EvolvePHP 2.0.0-alpha.1

- Version: `2.0.0-alpha.1`
- Stage: Alpha
- Release date: `2026-09-13`
- Tag: `2.0.0-alpha.1`

This release note summarizes the first EvolvePHP 2 Alpha surface. EvolvePHP 2 remains experimental, pre-release and not production-ready.

## Alpha Surface

- Core/runtime-neutral foundations for configuration, service registry, execution scopes, reset behavior, execution orchestration, lifecycle and CLI commands.
- HTTP foundations for PSR middleware, routing, routed dispatch, HTTP execution, response resolution, health handlers and the explicit response emission boundary.
- Module and plugin foundations for component identity, descriptors, dependency/capability graphs, restricted service registration, lifecycle, Composer plugin discovery and application-controlled enablement.
- Developer tooling for read-only Audit evidence, adoption planning declarations, Doctor diagnostics, route listing and development-only module/plugin starter generators.
- Bridge contracts, embedded PSR support, Laravel and Symfony adapters, remote HTTP JSON support and the isolated legacy PHP remote client.
- Skeleton developer experience for explicit CLI composition, configured commands and explicit route configuration.

## Requirements And Evidence

EvolvePHP 2 requires PHP 8.4. Current official framework CI evidence covers PHP 8.4 and PHP 8.5 for the root quality pipeline, tooling and package foundation.

The isolated legacy remote compatibility client has a separately documented PHP 7.4 compatibility boundary. That boundary is limited to the legacy client and does not lower EvolvePHP 2 framework or Core requirements below PHP 8.4.

Alpha APIs are experimental and breaking changes may occur before stable release. EvolvePHP 2 is not production-ready and this release note makes no production-readiness claim.

First-party packages are not yet independently published. Public application installation through published packages is therefore still limited by the current publication state, and this release note does not claim public package installation or package publication.

## Known Limitations

- Complete concrete web runtime, SAPI request creation, concrete response emission and production web bootstrap are not supplied yet.
- Public application installation through published packages is not available yet.
- Bridge compatibility depends on documented and tested combinations.
- Audit does not execute target code or certify migration readiness.
- Adoption planning records maintainer decisions only and does not automatically execute migration, cutover or rollback.
- Remote Bridge does not provide shared sessions, distributed transactions or automatic retries/fallback.
